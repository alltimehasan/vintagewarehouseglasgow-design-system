# Logos

The mark the client supplied, cut from its white background. It is a raster: ask for the original vector file before any print use.

- `logo-black.png` — the black disc with white marks (491px). On `surface` and `surface-raised` in the light theme: the site header, the invoice.
- `logo-white.png` — the same mark inverted: white disc, black marks. On `band` (the footer, over hero photos) and in the dark theme's header.
- `icon-512.png`, `icon-192.png`, `icon-180.png`, `icon-64.png`, `icon-32.png` — the black disc at favicon and app-icon sizes (512 and 192 for the web manifest, 180 for Apple touch icon, 64 and 32 for the favicon).

Keep clear space of a quarter of the disc's width around it. Never stretch it, recolour it, or set it smaller than 40px.
